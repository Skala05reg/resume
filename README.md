# Резюме разработчика 1С

Публичная ссылка: https://skala05reg.github.io/resume/

На сайте опубликована двухстраничная версия PDF. Стартовая страница открывает `resume.pdf`; при отключённом перенаправлении доступна прямая ссылка.

Источник для редактирования находится локально в `F:\Курсы 1С\Собеседования\Резюме 1С`: `resume_data.json`, `resume_two_page.json`, `build_two_page.py`. Запуск: `build_two_page.cmd`.

После сборки и проверки скопировать `output/pdf/Резюме 1С-разработчик - 2 страницы.pdf` в `resume.pdf`, проверить diff, сделать commit и push. GitHub Pages публикует корень ветки `main`. Ошибка сборки оставляет предыдущий PDF; публикация происходит только после push. В репозиторий публикации входят только готовый PDF, стартовая страница и документация.
